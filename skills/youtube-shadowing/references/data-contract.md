# Data contract (v1)

The assistant edits only `chunks/chunk-NNNN.result.json`. Scripts own raw captions,
metadata.json, source.json, prepared.json, chunk input files, study.json and the
publication receipt. Do not edit them to make a failed check pass.

## Input

The input JSON includes `schema_version: 1`, `chunk_id`, `chunk_hash`,
`source_hash`, `token_start`, `token_end`, `text`, `context_before` and
`context_after`. Word ranges are half-open: start included, end excluded.
`text` is the only material to output. Nearby context helps sentence boundaries.
Source times are kept internally and are never generated by the model.
Extraction binds caption provenance to the source hash. Metadata changes require
fresh extraction/preparation; never relabel automatic captions as human captions.

## Result

```json
{
  "schema_version": 1,
  "chunk_id": "chunk-0001",
  "chunk_hash": "COPY_THE_HASH_FROM_THE_CURRENT_INPUT",
  "sentences": [
    {"text": "I think we should start with a simple example.", "uncertain": false},
    {"text": "What would you do next?", "uncertain": false}
  ]
}
```

Use actual sentences from the input; the example above is illustrative.
`uncertain` defaults to false. `join_previous` defaults to false and is allowed
only on the first sentence of a later chunk. Optional explicit `token_start` and
`token_end` are checked against the ranges automatically inferred from text.
Omit them in normal use to avoid counting mistakes.

The tokenizer preserves English contractions, hyphenated words and quantities
such as `$25`, `3.14`, `1,000`, `12:30` and `25%`. Do not expand, reformat or
otherwise change those forms. Typographic versus straight apostrophes and case
are normalized during validation. A missing/stale chunk hash is rejected.

## Completion and recovery

Every successful result is retained on disk. `next` returns the first missing or
invalid block and its concrete error. `validate --chunk ID` checks one block;
`validate` checks the full transcript and writes study.json only if all pass.
`render` repeats the complete checks and rebuilds study.json before layout.

PDF output includes the video title, channel, provenance, full source URL,
numbered sentences and replay annotations. A source hash and a PDF byte hash in
the cache identify an owned output; unknown or user-modified PDFs are preserved
with a new filename. Configuration and source files are not put in the visible
learning library.
